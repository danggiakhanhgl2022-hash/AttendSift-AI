## Bối cảnh và tài liệu lịch sử

Các file `VERIFICATION_*`, `RELEASE_NOTES_*`, `PUBLISH_*` và báo cáo ngày cũ được giữ để truy lịch sử. Ví dụ mô tả Excel 4 sheet trong báo cáo cũ có thể đúng với lần chạy đó; tài liệu hiện tại mô tả 5 sheet cho phiên có danh sách nhân viên. Tạo phiên mới để dùng quy tắc phân tích mới, không coi việc cập nhật README là cập nhật dữ liệu lịch sử.
