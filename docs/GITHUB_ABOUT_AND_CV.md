# Nội dung giới thiệu — AttendSift AI 1.1.0

## GitHub About

> Hỗ trợ chấm công từ Chatwork: phân tích bằng AI, đối chiếu tin gốc, rà soát và xuất Excel 5 sheet. Windows Local và website cloud.

## Topics

`python`, `flask`, `chatwork`, `attendance`, `excel`, `sqlite`, `postgresql`, `windows`, `vercel`, `ai`

## Giới thiệu ngắn

AttendSift AI hỗ trợ chuyển báo cáo Chatwork thành sự kiện chấm công theo nhân viên và ngày, có đối chiếu nguồn và kiểm tra trước khi xuất Excel. Bản Windows Local dùng SQLite, bản cloud dùng PostgreSQL. Phiên bản 1.1.0 bổ sung giờ Việt Nam, sửa cron và lưu dữ liệu cloud trong 3 tháng. Đây là bản ứng viên phát hành; kết quả kiểm chứng được ghi riêng.

Không mô tả là được diễn đàn chứng nhận, chính xác 100%, bảo mật tuyệt đối hoặc miễn phí không giới hạn.
