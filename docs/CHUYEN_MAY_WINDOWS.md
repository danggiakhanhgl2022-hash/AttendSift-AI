# Chuyển máy Windows — phiên bản công khai

Chỉ chuyển ứng dụng và mã nguồn công khai trong repo. Database, khóa đã lưu, danh sách nhân viên và file Excel thật là dữ liệu riêng, cần chuyển qua kênh bảo mật phù hợp theo chính sách công ty. Trên máy mới, cấu hình lại khóa API và nhập nhân viên bằng giao diện; không thêm dữ liệu nội bộ vào gói GitHub.
